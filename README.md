# Josh Raja Portfolio

A responsive personal portfolio built with React and Vite. Its layout and visual language follow [Gazi V2](https://github.com/gazijarin/Gazi-V2) by Gazi Jarin. The implementation and particle illustration were rebuilt for Josh, with the original author's biography, work, and images removed.

## Local development

```sh
npm ci
npm run dev
```

Run `npm run lint` and `npm run build` before publishing. Vercel can import the repository as a Vite project with `npm run build` and `dist` as the output directory.

## Personalization before launch

Edit the `profile`, `focusTabs`, and `project` values near the top of `src/App.jsx`. Add a verified email address, GitHub and LinkedIn links, and real experience and project descriptions. Until then, the site intentionally shows only this portfolio as work and does not publish an unverified contact address.

The design uses no proprietary images or content from the original portfolio.
